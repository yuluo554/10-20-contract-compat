## 六、发布计划（M6 预演，纪律先落）

1. 本机全量：双解释器 pytest + 布局门 + 三场景 CLI + golden `--check`。
2. `git clone --no-local` 到仓库外 → 新 venv → 按 README 逐条跑（**发布包没有 `.git`**，判据要两态）。
3. `git tag -a v0.1.0` → `git archive` 源码包 + `gzip -9n` + `SHA256SUMS`。
4. `gh repo create yuluo554/10-20-contract-compat --public`（或已有则确认）→ push → CI。
5. `gh release create v0.1.0 <附件> --notes-file ...`；README 的产物名必须真在 Release 里。
6. 真下载附件 → 中立目录 → 解包 → 与 `git archive` 树共有文件逐字节比对。
7. 写 `plan/RELEASE-M6.md` 两栏 + 覆盖对账表；tag 后只允许非交付面提交。
